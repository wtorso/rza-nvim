# RZA для Neovim

[English version](README.md)

Подсветка синтаксиса и необязательная поддержка Language Server Protocol для файлов `.rza` в
Neovim. Для подсветки компилятор RZA не нужен. Необязательный LSP-клиент запускает тот же сервер
`rez3asm --lsp`, который используют другие редакторы RZA; отдельной реализации правил языка в
этом репозитории нет.

## Возможности

- Определение filetype и настройка комментариев `; %s`.
- Подсветка инструкций, регистров, записей, полей, чисел и комментариев.
- Все 240 активных сочетаний целочисленных и floating-point операций и типов, включая строгие
  f32/f64 преобразования и bitcasts.
- Необязательная диагностика и стандартные возможности Neovim LSP через настоящий сервер RZA.
- Не требуются менеджер плагинов, tree-sitter, npm или внешние Lua-зависимости.

Поддерживается Neovim 0.9 или новее.

## Установка

Клонируйте репозиторий:

```sh
git clone --depth 1 https://github.com/wtorso/rza-nvim.git
```

Добавьте его в `runtimepath` в `init.lua`:

```lua
vim.opt.runtimepath:append("/absolute/path/to/rza-nvim")
vim.cmd("filetype plugin on")
vim.cmd("syntax enable")
```

Перезапустите Neovim. При открытии `.rza` включаются filetype `rza` и подсветка. Компилятор для
этой конфигурации не требуется.

## Необязательный LSP

Соберите или установите `rez3asm` по
[инструкции проекта RZA](https://github.com/wtorso/rza#build-and-run), затем один раз вызовите
`setup` в `init.lua`:

```lua
require("rza").setup()
```

По умолчанию клиент запускает `rez3asm --lsp` из `PATH`. Чтобы указать компилятор явно:

```lua
require("rza").setup({
    cmd = { "/absolute/path/to/rez3asm", "--lsp" },
})
```

Клиент запускается при определении filetype RZA. Стандартные функции Neovim LSP предоставляют
диагностику, подсказки при наведении, определения, ссылки, автодополнение и переименование,
поддерживаемые сервером RZA. Собственных сочетаний клавиш плагин не задаёт.

Вызывайте `setup` только если нужен LSP. Загрузка syntax, filetype и ftplugin не запускает
клиент и не требует компилятор.

## Проверка

Установите Neovim и выполните тесты подсветки, которым компилятор не нужен:

```sh
bash test/run.sh
```

Чтобы дополнительно запустить настоящую LSP-интеграцию, укажите исполняемый компилятор:

```sh
RZA_COMPILER=/absolute/path/to/rez3asm bash test/run.sh
```

LSP-тест использует ограниченные ожидания и проверяет корректный документ без диагностики и
некорректный документ с ожидаемым сообщением `unknown op bogus`. CI выполняет оба режима на
Ubuntu.
